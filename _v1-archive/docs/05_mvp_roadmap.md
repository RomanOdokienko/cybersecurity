# MVP Roadmap

Версия: 2026-04-16

## 1. Цель ближайшего этапа
Стабилизировать процесс прогона 10-20 доменов в день с минимальным числом ложных sales-тезисов.

## 2. Приоритет P0
1. Зафиксировать и валидировать quick v2 на выборке 30-50 доменов.
2. Отдельно измерить false fail по 152-ФЗ.
3. Привести `next_action` к бизнес-логике оффера (без перекоса в offer_now).

## 3. Приоритет P1
1. Добавить в dashboard блок дельты `quick v1 vs v2`.
2. Вести baseline-метрики конверсий в `data/` или отдельной таблице.
3. Стандартизировать шаблон manual-валидации для спорных кейсов.

## 4. Приоритет P2
1. Улучшить покрытие JS-форм в полуавтоматическом режиме.
2. Добавить более устойчивый reputation/OSINT слой.
3. Подготовить версию dashboard для внешней демонстрации.

## 5. Критерии готовности MVP
1. Устойчивый daily throughput (10+ доменов/день).
2. Доля ложных тревог контролируема и снижается.
3. Продажный оффер формируется воспроизводимо и объяснимо.
