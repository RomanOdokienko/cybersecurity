# Детальный 152-ФЗ screening: dr-knyazkin.ru

Дата проверки: 2026-04-15
Режим: пассивный аудит публичных данных (без авторизации/без эксплуатации)

## Важно
Это технический compliance-screening по публичным артефактам сайта, а не юридическое заключение.
Часть требований 152-ФЗ проверяется только по внутренним документам оператора и не может быть подтверждена снаружи.

## Итог (web-visible)
- Оценка готовности по публичному контуру: **48/100**
- Риск: **medium-high**
- Ключевой gap: **модель согласия на сайте (чекбокс не на всех формах + отсутствие отдельного текста согласия по форме, требуемой ст. 9)**

## Что зафиксировано фактами
- Главная страница содержит 7 web-форм, все отправляются методом `POST`.
- На 4 из 7 форм есть обязательный consent checkbox (`data-field-type="cb"`, `data-tilda-req="1"`, `aria-required="true"`).
- На 3 из 7 форм обязательный чекбокс в пределах `<form>...</form>` не обнаружен.
- В формах есть ссылки на `https://dr-knyazkin.ru/politika` и тексты «Я соглашаюсь с политикой конфиденциальности» / «Я даю согласие на обработку данных».
- Страница `https://dr-knyazkin.ru/politika` содержит политику ООО «КЛИНИКА ДОКТОРА КНЯЗЬКИНА»: цели, категории субъектов, категории ПДн, правовые основания.
- На сайте есть cookie-баннер («Веб-сайт использует файлы cookie», кнопка «Принять»).
- Подключена Яндекс.Метрика (`mc.yandex.ru/metrika/tag.js`), есть атрибут `data-tilda-cookie-type="analytics"` (требуется ручная браузерная валидация блокировки до consent).

## Критичные для оффера (P1)
1. **Согласие по формам неравномерно реализовано**: 3 из 7 форм без обязательного checkbox в пределах формы.
2. **Нет подтвержденного отдельного текста согласия под требования ст. 9 (ред. 24.06.2025)** для веб-сценария.
3. **Policy неполная по обязательным практическим секциям**: права субъекта, отзыв, сроки, уничтожение, передача/поручение, локализация.

## P2 (улучшения)
1. Добавить версионность policy (дата вступления в силу/обновления).
2. Добавить в policy явный канал для запросов субъекта ПДн (email/почтовый адрес/форма) и SLA ответа.
3. Подтвердить/документировать поведение analytics-cookie до согласия пользователя.
4. Вынести отдельный документ «Согласие на обработку ПДн» для онлайн-форм и связать с каждой формой.

## Рекомендуемый план работ
- 0-3 дня: унифицировать все формы (обязательный checkbox + единый consent-блок + явная ссылка на отдельное согласие).
- 3-7 дней: обновить policy до полной структуры (права/сроки/уничтожение/передача/локализация/каналы запросов).
- 7-14 дней: закрыть governance-часть (проверка уведомления РКН по ст. 22, подтверждение ответственного по ст. 22.1, журнал доказательств consent).
