# Remediation Plan Template

## Immediate (0-30 days)
1. Fix critical internet-facing misconfigurations.
2. Remove sensitive file exposures.
3. Enforce HTTPS and baseline security headers.

## Short Term (31-60 days)
1. Harden admin surface and CMS footprint.
2. Improve form privacy/compliance controls.
3. Reduce risky third-party script dependencies.

## Medium Term (61-90 days)
1. Implement email-domain anti-spoofing hardening.
2. Improve monitoring and periodic re-check cadence.
3. Add evidence-based security governance checkpoints.
