Общие правила

  • Один агент = одна клиника = один прогон.
  • Проверка в браузере с рендерингом JS + анализ audit JSON.
  • Результат строго бинарный: ок или проблема.
  • Fallback-эвристики не используются: статус ставится только по фактически найденным сигналам (PoC).

1. Пациент не давал согласия на обработку данных

ок: на всех формах найден маркер согласия (чекбокс или корректный текст согласия). проблема: есть формы без маркера согласия. Предустановленный чекбокс оценивается отдельно в п.2.

2. Согласие подставлено автоматически — это хуже чем его отсутствие

ок: нет предустановленных чекбоксов согласия. проблема: есть хотя бы один prechecked-чекбокс.

3. На сайте нет обязательного документа об обработке данных пациентов

ок: найдена реальная ссылка/страница политики ПДн из навигации/контента сайта (с PoC URL/контекста). проблема: доказательство не найдено.

4. Имя и телефон пациента передаются в открытом виде — любой может перехватить

ок: формы не отправляют данные на HTTP (используется HTTPS). проблема: найден хотя бы один HTTP action.

5. На сайте упоминается организация, признанная в России экстремистской

ок: упоминаний Meta/Instagram/Facebook/Threads не найдено. проблема: найдено хотя бы одно релевантное упоминание.

6. Сайт собирает данные пациентов без их уведомления

ок: найдены признаки уведомления о cookies/согласии. проблема: признаки не найдены.

7. Яндекс.Метрика собирает данные ваших пациентов — в политике об этом ни слова

ок: либо Метрика не найдена, либо найдена и упомянута в политике/документах. проблема: Метрика найдена, но упоминаний в политике нет.

Общие правила

  • Один агент = одна клиника = один прогон.
  • Проверка в браузере с рендерингом JS.
  • Результат строго бинарный: ок или проблема.
  • Если сигнал противоречивый, статус не ставим до ручного обсуждения.

1. Нет онлайн-записи со слотами

ок: есть рабочая онлайн-запись: либо выбор даты/времени (слоты), либо отдельная рабочая страница записи. проблема: только форма/звонок без онлайн-инструмента записи.

2. Сайт — цифровая визитка, не инструмент

ок: страниц сайта >= 5. проблема: страниц сайта <= 4.

3. Вы не знаете кто приходит на сайт и почему уходит

ок: аналитика установлена (Яндекс.Метрика/аналог). проблема: аналитика не найдена. Признаки целей/событий фиксируются отдельно как quality-flag в PoC и не являются автоматическим фейлом.

4. Пациент не может написать первым

ок: есть хотя бы один рабочий канал первого письменного контакта (WhatsApp/Telegram/Max/онлайн-чат/форма сообщения). проблема: нет ни одного рабочего канала для первого письменного контакта.

5. Прайс-лист доступен без регистрации

ок: найдена публичная страница цен без логина/регистрации и с ценовым контентом. проблема: не найдена.

6. Schema.org Поддерживаемые схемы Schemaorg от Яндекса

ок: найден хотя бы один поддерживаемый тип из whitelist (Organization/Medical*/LocalBusiness и др.). проблема: поддерживаемые типы не найдены.
